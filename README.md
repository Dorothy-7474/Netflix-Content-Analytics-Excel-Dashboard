# Netflix Content Analytics Dashboard Using Microsoft Excel

## Project Overview

This project focuses on analyzing Netflix content data using Microsoft Excel to uncover insights into content distribution, ratings, audience engagement, popularity, and release trends. The project transforms raw data into meaningful information through data cleaning, calculated columns, PivotTables, charts, KPIs, and an interactive dashboard.

The goal is to understand how Netflix content varies across genres and content types, explore IMDb and TMDB ratings, and identify patterns in audience engagement and content popularity.

## Project Objectives

- Analyze the distribution of movies and TV shows across genres.
- Explore content release trends across different years and decades.
- Compare IMDb ratings and TMDB ratings to understand content quality.
- Examine audience engagement using IMDb vote counts.
- Categorize content based on ratings, runtime, and popularity.
- Build an interactive Excel dashboard for effective data visualization and analysis.

## Tools and Techniques

- **Microsoft Excel**
- Data Cleaning and Transformation
- Excel Formulas and Calculated Columns
- PivotTables and PivotCharts
- KPI Development
- Interactive Slicers and Filters
- Dashboard Design and Data Visualization

## Key Analysis Areas

1. **Content Overview:** Analyzes content distribution by genre, type, and release decade.
2. **Rating and Quality:** Examines IMDb ratings, rating categories, and TMDB ratings to understand content quality.
3. **Audience and Popularity:** Explores IMDb votes, TMDB popularity scores, and popularity categories.
4. **Release and Runtime Analysis:** Investigates release-year trends, runtime categories, and average runtime by content type.

## Key Insights

- Netflix's content catalog includes a diverse mix of movies, TV shows, and genres.
- Drama performs strongly in terms of average IMDb ratings in the analyzed dataset.
- Mystery & Thriller stands out in the analysis of overall TMDB popularity.
- High ratings do not necessarily mean that a title has equally high popularity.
- Categorizing popularity scores helps distinguish between content with different levels of visibility and audience interest.
- Release-year and runtime analysis helps reveal patterns in the content catalog.

## Business Value

The dashboard demonstrates how Excel can be used to convert raw content data into actionable insights. These findings can support content performance analysis, audience engagement evaluation, and the identification of highly rated titles that may benefit from greater visibility.
